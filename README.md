# 🌟 ھەشەمەتلىك چىراقلىق كىرىش ۋە تىزىملىتىش بېتى (Luxury Interactive Lamp Login & Register)

تەبىئىي فىزىكىلىق تارتىپ ئوينايدىغان چىراق يىپى، 360 گرادۇسلۇق ئايلانما نۇر ئېففېكتى، سىلىق 3D كارتىلارنى ئالماشتۇرۇش ۋە ئۇيغۇرچە خەت نۇسخىلىرى تولۇق قوللانغان يۇقىرى تېخنىكىلىق كىرىش/تىزىملىتىش بېتى.

---

## ✨ ئالاھىدىلىكلىرى (Features)

1. **تەبىئىي فىزىكىلىق مىس چىراق زەنجىرى (2D Spring & Pendulum Cord):**
   - سىلكىپ ئويناش، تارتىش، تاشلاش ھەرىكەتلىرى ھەقىقىي مېخانىك ئاۋاز (Mechanical Click & Twang) بىلەن تەمىنلەنگەن.
   - چىراقنىڭ تۈگمۈكى، زەنجىرى ۋە يۇمشاق نۇر دەستىسى (Volumetric Light Beam) ئۆلچەملىك لايىھەلەنگەن.

2. **360° ئايلانما نۇر ۋە تېزلىشىش ئېففېكتى (Conic Light & Active Focus):**
   - كىرگۈزۈش رامكىسىغا خەت يازغاندا نۇر ئايلىنىشى ئاپتوماتىك تېزلىشىپ كۆرۈنۈش جەلپكارلىقىنى ئاشۇرىدۇ.

3. **3D پىرقىرايدىغان قوش كارتىلىق لايىھە (3D Flipping Card):**
   - «كىرىش» ۋە «ھېسابات قۇرۇش» ئوتتۇرىسىدا سىلىق 3D پىرقىراپ يۆتكىلىدۇ.

4. **ئويا ۋە مەرۋايىت يۇمىلاق ئۇچۇش ھەرىكەتچان ئېففېكتى (Interactive Flying Check & Circle Transitions):**
   - باسىلغاندا ئويا بەلگىسى سول تەرەپكە ئۇچۇپ كېتىپ، مۇۋەپپەقىيەتلىك ھالەت مەرۋايىت نۇرلۇق يۇمىلاق ھالەتتە ئىشىك ئېچىپ كىرىدۇ.

5. **ئۇيغۇرچە خەت نۇسخىلىرى ۋە RTL تولۇق قوللاش:**
   - ئەلكاتىپ (ALKATIP) خەت نۇسخىلىرى تولۇق قىستۇرۇلغان.

---

## 🚀 ئىشلىتىش ئۇسۇلى (Getting Started)

### بىۋاسىتە ئىجرا قىلىش:
`index.html` ھۆججىتىنى تور كۆرگۈچ (Chrome, Edge, Firefox) ئارقىلىق ئاچسىڭىزلا بولىدۇ.

### Node.js ئارقىلىق يەرلىك مۇلازىمېتىردا ئېچىش:
```bash
node server.js
```
ئاندىن كۆرگۈچتە `http://localhost:5500` نى ئېچىڭ.
